Find your actual fit.

Print a matched three-position clearance gauge before committing to a large modular assembly. Each numbered position uses the same rectangular peg with a different socket clearance. Export both printable plates as STL files, with no screws or glue.

01 / TEST SETTINGS

Clearance sweep

These are clearance coupons, not snap-lock connectors or structural test specimens. The pegs are intentionally straight and can be pulled back out. Test with the same filament, nozzle, slicer settings, and print orientation as your final assembly.

02 / MATCHED GEOMETRY

Top-view assembly map

All dimensions are millimeters. Each slot grows on both sides, so its width is peg width + 2 × clearance. Its length also grows by twice the clearance.

03 / DOWNLOAD & TEST

Two STL files. Three fits.

  1. Import both files into Bambu Studio at 100% scale, with each flat face on the bed.
  2. Print both in the same material and with the same quality profile you'll use later.
  3. Insert each peg into its numbered matching opening. Don't force it.
  4. Record which is snug, sliding, and loose. Use that clearance as a starting point in the dovetail generator.

Export geometry: 70 × 25 mm plates, 3 equally spaced 8–12 mm pegs, with through-openings in the socket plate. You can reprint the plate cheaply as settings change.
